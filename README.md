## 🌱 เกี่ยวกับโปรเจกต์นี้ (ฉบับมือใหม่กำลังงม!)
สวัสดีค่ะทุกคน! Repository นี้เป็นพื้นที่รวบรวมงานออกแบบหน้าเว็บไซต์ (HTML & CSS) ที่เพิ่งลองฝึกทำ ยอมรับเลยว่าช่วงแรกๆ มีมึนตึ้บกับพวกโค้ดและการจัดเลย์เอาต์พอสมควร แต่ก็ค่อยๆ ลองผิดลองถูก เปิดเว็บดูรีวิว จนออกมาเป็นหน้าเว็บเหล่านี้ค่ะ 

ทำส่งอาจารย์แล้ว ก็เลยขอแปะเก็บไว้เป็นโน้ตส่วนตัว เผื่อวันไหนลืมคำสั่ง CSS จะได้กลับมาแอบดูโพยตัวเองตรงนี้แหละ 📖✍️
